01｜認識程式設計

程式是人撰寫的一群指令，用來命令電腦完成工作、解決問題。例如在文書軟體中剪下、貼上文字，背後就有程式指令協助完成。

程式（Program）讓電腦依序執行的指令。
程式語言人與電腦溝通、表達解題步驟的工具。
C / C++本課程使用的程式語言，學習基本語法與解題方法。

程式設計的基本流程

分析問題 → 撰寫程式 → 編譯檢查 → 執行與測試

本章先學會輸出文字，之後的章節再逐步加入變數、輸入、判斷與重複執行。

03｜第一支 C++ 程式

範例 1-1：在螢幕上印出 Hello world，將程式儲存為 範例1-1.cpp。

#include <iostream>using namespace std;int main() { cout << "Hello world" << endl; return 0;}

程式執行結果

Hello world

閱讀順序

① 引入標頭檔 → ② 進入 main() → ③ 執行 cout 輸出 → ④ 程式結束。

上面是可直接編譯的現代 C++ 完整範例；原講義的示意圖片未直接嵌入此版本，改以可複製程式碼呈現。

04｜編譯、執行與除錯

寫好程式後，必須先編譯（Compile），再執行（Run）。編譯器會檢查程式是否符合語法，並產生可執行檔。

範例1-1.cpp → 編譯器檢查 → 範例1-1.exe → 執行並輸出

試著找出錯誤

下列程式少了什麼？

#include <iostream>using namespace std;int main() { cout << "Hello world" return 0;}

選擇後會顯示解析。

講義提到的 expected ';' before ... 常表示前一個敘述結尾缺少分號。編譯成功不代表邏輯一定正確，仍需實際執行與測試。

.cpp 與 .exe

副檔名用途
.cppC++ 原始程式碼，可閱讀與修改。
.exe在相容的 Windows 環境中可執行的程式檔；不等於可在所有電腦直接執行。

05｜認識程式結構

每一支可獨立執行的 C++ 程式，都需要有程式進入點 main()。C++ 區分大小寫，並可利用空白與縮排提高可讀性。

#include <iostream> // 引入輸入輸出標頭檔using namespace std; // 使用標準命名空間int main() { // 主程式開始 // 單行註解：這一行不會執行 /* 多行註解： 可以跨越數行 */ cout << "Hello"; // 分號表示敘述結束 return 0;} // 主程式結束
符號／語法作用
#include <iostream>引入標準輸入輸出功能。
int main()程式執行的進入點。
{ }界定程式區塊的開始與結束。
;多數敘述結尾需要分號。
//單行註解。
/* ... */多行註解。

補充：using namespace std; 是為初學者方便使用 cout 的寫法；也可以改寫成 std::cout。

06｜螢幕輸出 cout

cout 可以把文字或變數值輸出到螢幕；使用 << 串接輸出內容。endl 和 \n 都能換行。

寫法效果
cout << "Hello";顯示 Hello
cout << "Hello" << endl;顯示 Hello 後換行
cout << "Hello\n";顯示 Hello 後換行
cout << "A" << endl << "B";分兩行顯示 A、B

互動：修改輸出文字

模擬執行結果

07｜特殊控制字元

當輸出內容包含換行、雙引號、反斜線等特殊字元時，可以使用跳脫序列（Escape Sequences）。

控制字元作用範例
\n換行cout << "A\nB";
\t水平定位cout << "A\tB";
\"輸出雙引號cout << "\"Hello\"";
\\輸出反斜線cout << "C:\\CPP";
\a提示音（視環境支援）cout << "\a";

08｜學生實作練習

以下兩題保留原講義題意。建議先自行寫程式，遇到困難再展開提示。

習題 1-1｜輸出文字與雙引號

在螢幕印出以下兩行文字，第二行必須包含雙引號，並發出「嗶」聲。

Hello World. "I love the world."
需要提示？
使用 cout 輸出文字；雙引號要寫成 \"，換行可用 endl 或 \n；提示音可試 \a（依電腦環境可能沒有聲音）。

習題 1-2｜輸出星號圖形

使用 cout 印出下列圖形。

＊ ＊＊＊ ＊＊＊＊＊ ＊＊＊＊＊＊＊ ＊ ＊
需要提示？
每一列可以分別使用一個 cout，注意前面的空白數量與換行。也可以使用 \n 把多列串在同一個字串中。
