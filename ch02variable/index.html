01｜變數是什麼？

「變數」是用來存放程式執行時所需資料的名稱，對應到記憶體中的一塊空間。

變數的用途

程式可以用變數儲存分數、數量、身高、金額等資料，後續再進行計算或輸出。

數值改變，記憶體內容也改變

當 score 從 80 改成 95，變數所存放的值就更新了。

變數名稱score
資料型態int
目前儲存值80

此動畫示範「變數的值會改變」，不是實際記憶體位址。

不同資料型態需要的記憶體空間不盡相同。例如，char 通常佔 1 byte，int 在常見的編譯環境中佔 4 bytes；可以使用 sizeof() 查看實際大小。

sizeof 範例 · C++ 
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(int) << endl;
    cout << sizeof(char) << endl;
    return 0;
}

資料型態的大小與可表示範圍可能因編譯器、系統而不同；實際執行可用 sizeof() 確認。

建議使用有意義的英文名稱命名，例如 score 代表分數、level 代表等級，方便日後閱讀。

03｜常用資料型態

變數的「資料型態」決定可以存放什麼種類的資料，例如整數、浮點數和字元。

資料型態C++ 語法常見大小範例與用途
整數 integerint4 bytes數量、商、餘數；例如 100
浮點數 floatfloat4 bytes可表示小數；例如 61.5
字元 characterchar1 byte單一字元；例如 'A'、'5'

特別留意：'5' 是字元，5 是整數；"A" 是字串常值，'A' 才是單一字元常值。

不同資料型態 · C++ 
#include <iostream>
using namespace std;

int main() {
    int money = 10000;
    float rate = 1.8;
    char level = 'A';
    cout << money << endl;
    cout << rate << endl;
    cout << level << endl;
    return 0;
}

04｜變數宣告與生命週期

4-1｜宣告語法

使用變數前，先告訴編譯器變數名稱與資料型態。

語法說明
int score;宣告一個整數變數
float num1, num2;一次宣告兩個浮點數變數
int score = 80;宣告時同時設定初始值

4-2｜區域變數與全域變數

區域變數（Local Variable）：在函式或區塊內宣告，通常只在所屬區塊的作用範圍內使用，離開區塊時生命週期結束。

全域變數（Global Variable）：在函式外宣告，可由適當範圍內的函式使用。例如，可在 main() 之前宣告。

作用範圍示例 · C++ 
#include <iostream>
using namespace std;

int globalScore = 90; // 全域變數

int main() {
    int localScore = 80; // 區域變數
    {
        int bonus = 5; // 僅在這個區塊內使用
        cout << localScore + bonus << endl;
    }
    cout << globalScore << endl;
    return 0;
}

05｜指定運算子：一個等號 =

在 C++ 中，= 是指定運算子：將右邊的值或運算結果，儲存到左邊的變數。它不同於數學中左右可以互換的等號。

✓ 正確

score = 80;

ch = 'A';

✗ 錯誤

80 = score;：左邊不能是數字常值。

ch = A;：若要指定字元 A，須使用單引號。

互動｜更新 score 的值

score = 80

這裡以模擬方式解釋指定運算，並未在網頁中編譯 C++。

指定值範例 · C++ 
#include <iostream>
using namespace std;

int main() {
    int score;
    char ch;
    score = 80;
    ch = 'A';
    cout << score << endl;
    cout << ch << endl;
    return 0;
}

6-2｜固定小數位數 fixed、setprecision()
使用 #include <iomanip>，搭配 fixed << setprecision(2)，即可固定顯示小數點後兩位。
顯示小數位數 · C++ 
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << fixed << setprecision(2);
    cout << 3.14159 << endl; // 3.14
    return 0;
}
互動｜設定顯示小數位數
以上是 JavaScript 顯示模擬；浮點數精度和臨界四捨五入結果應以實際 C++ 執行為準。
6-3｜補足位數 setw()、setfill()
例如：cout << setw(2) << setfill('0') << 9 << endl;，可顯示 09。
補零顯示 · C++ 
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << setw(2) << setfill('0') << 9 << endl;
    return 0;
}


07｜算術運算
除了將值放入變數，也可以直接將運算式的結果指定給變數。
運算子意義範例
+加法8 + 3 → 11
-減法8 - 3 → 5
*乘法8 * 3 → 24
/除法8 / 3 → 2（兩邊都是 int）
%取餘數8 % 3 → 2
( )控制運算優先順序(2 + 3) * 4 → 20
請記住：兩個整數相除，整數商的小數部分會被捨去；% 取餘數僅能使用整數運算元。程式中的乘號是 *，不是 ×。

08｜範例
接著透過兩個完整的 C++ 程式，練習變數宣告、指定值、輸出，以及算術運算。
範例 2-1｜將值指定給變數並輸出
先宣告整數及字元變數，將 100 與 'A' 指定給變數，再使用 cout 顯示。
範例 2-1 · 完整程式 
#include <iostream>
using namespace std;

int main() {
    int num;
    char ch;
    num = 100;
    ch = 'A';
    cout << num << endl;
    cout << ch << endl;
    return 0;
}
執行結果
100
A
閱讀重點
先宣告、再指定、最後輸出。單一字元要加單引號。
進一步想想將 100 改為其他整數，或將 'A' 改為 'B'，重新編譯執行後觀察輸出如何改變。
範例 2-2｜指考加權總分
國文 61.5 分、英文 55.75 分、數學 72.5 分；採計方式為「國文 × 1.5 ＋ 英文 × 1.5 ＋ 數學 × 2」。
範例 2-2 · 完整程式 
#include <iostream>
using namespace std;

int main() {
    float chinese = 61.5;
    float english = 55.75;
    float math = 72.5;
    float total = (chinese + english) * 1.5 + math * 2;
    cout << "總分為" << total << endl;
    return 0;
}
執行結果
總分為320.875
程式解說
括號先計算國文與英文分數總和；之後乘上加權倍率，再加上數學加權分數。

習題 2-1｜圓的面積
令 pi = 3.14，在程式碼中設定圓的半徑 r 公尺，將半徑及面積 area 顯示在螢幕上。
需要提示？面積公式：area = pi * r * r;，注意先宣告浮點數變數，再使用 cout 輸出。


習題 2-2｜存款、利率與等級
小明在銀行有 10000 元，年利率為 1.8%，客戶等級為 'A'。使用三個變數 level、money、rate，顯示：
等級: A
存金: 10000
利率: 1.8
需要提示？考慮以 char level = 'A';、int money = 10000;、float rate = 1.8; 宣告並指定值，再分行輸出。


習題 2-3｜華氏轉攝氏
攝氏溫度 c 與華氏溫度 f 的關係為 c = (f - 32) * 5 / 9。求華氏 95 度相當於攝氏幾度。
需要提示？用 float 儲存華氏與攝氏溫度；注意避免不必要的整數除法問題，例如寫成 (f - 32) * 5.0 / 9。


習題 2-4｜英哩轉公里
設計程式將大聯盟投手的球速由英哩（mile）換成公里（km）。
需要提示？已知 1 英哩 = 1.6 公里；可以宣告 float mile 與 float km，計算 km = mile * 1.6;。


習題 2-5｜BMI
在程式中設定體重 w 公斤、身高 h 公尺，顯示 BMI 值。
需要提示？以公尺為單位，公式為 BMI = w / (h * h)。請檢查身高不為 0。


習題 2-6｜整數相除的商與餘數
設定兩個整數 m 與 n，求 m 被 n 除的商與餘數。
需要提示？利用 m / n 計算整數商，利用 m % n 計算餘數；n 不能為 0。


習題 2-7｜秒數轉時：分：秒
將 39016 秒轉換為「時:分:秒」的格式。
需要提示？1 小時為 3600 秒。小時：39016 / 3600；剩餘秒數：39016 % 3600；接著以 60 換算分鐘與秒數。
