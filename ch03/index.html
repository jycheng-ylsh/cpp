cin 鍵盤輸入

讓程式接收使用者輸入：從 cin 讀取資料、計算成績、交換變數，到完成實作練習與程式闖關。

cin 語法範例交換變數習題章節測驗

01｜從設定值到鍵盤輸入

前一章學會使用 = 將固定的值指定給變數；這一章要讓使用者在執行程式時輸入資料，讓相同程式能處理不同數值。

固定指定

int score = 80;

每次執行都使用程式中指定的數值。

鍵盤輸入

cin >> score;

程式執行到此行會等待使用者輸入，輸入成功後將數值存入 score。

本章以 C++ 的 cin 為主，稍後也會比較 C 語言的 scanf() 輸入方式。

02｜cin 的基本語法

cin 從標準輸入讀取資料，搭配 >> 將資料依序存入變數。

語法作用
cin >> 變數;讀取一筆資料，存入指定變數。
cin >> 變數1 >> 變數2;依序讀取兩筆資料並分別存入兩個變數；可以用空白或換行分隔。
讀取一個整數 · C++ 
#include <iostream>
using namespace std;

int main() {
    int score;
    cout << "請輸入成績? ";
    cin >> score;
    cout << "你的成績是" << score << endl;
    return 0;
}
cout 與 cin 各有任務：cout << 顯示提示或結果；cin >> 將鍵盤輸入的資料讀進變數。兩者箭頭方向不同。
一次讀取兩個整數 · C++ 
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "請輸入兩個整數: ";
    cin >> a >> b;
    cout << "總和為" << a + b << endl;
    return 0;
}

03｜輸入流程與緩衝區

fflush(stdin);：清除輸入緩衝區資料（部分編譯器提供的用法）。

認識輸入緩衝區

stdin 是 standard input（標準輸入），通常接收鍵盤輸入。使用者輸入的資料會先放進輸入緩衝區，再由程式讀取。

輸入緩衝區是記憶體中暫時存放輸入資料的空間。

為什麼要清除輸入緩衝區？

例如，讀完數字後接著讀取字元或整行文字，緩衝區中可能仍留有換行符號等未讀取資料，影響接下來的輸入。此時需要適當處理剩餘資料。

部分舊版開發環境中的寫法 
fflush(stdin); // 嘗試清除標準輸入緩衝區（非標準 C++ 用法）
重要提醒：fflush(stdin) 不是標準 C++ 保證可用的清除鍵盤輸入方法，效果會依編譯器而異。使用 C++ 的 cin 時，可用 cin.ignore() 略過一個輸入字元；若需清除整行剩餘內容，則要使用其他處理方式。
標準 C++：清除本行剩餘輸入 · 完整範例 
#include <iostream>
#include <limits>
#include <string>
using namespace std;

int main() {
    int age;
    string name;
    cout << "請輸入年齡：";
    cin >> age;
    cin.ignore(numeric_limits<streamsize>::max(), '\n');
    cout << "請輸入姓名：";
    getline(cin, name);
    cout << name << "，" << age << "歲" << endl;
    return 0;
}
提醒：cin.ignore(); 預設只略過一個字元，適合處理一般輸入後留下的單一換行字元，並不等於清空整個輸入緩衝區。

04｜範例 3-1｜輸入兩科成績，計算總分與平均

請使用者依序輸入兩科成績，計算並顯示總分與平均。變數 a、b 儲存成績，sum、ave 儲存運算結果。

範例 3-1｜完整程式 · C++ 
#include <iostream>
using namespace std;

int main() {
    float a, b;
    float sum, ave;
    cout << "請輸入第一科成績? ";
    cin >> a;
    cout << "請輸入第二科成績? ";
    cin >> b;
    sum = a + b;
    ave = sum / 2;
    cout << "總分為" << sum << endl;
    cout << "平均為" << ave << endl;
    return 0;
}

執行順序

  1. 宣告四個 float 變數。
  2. 顯示第一科提示，等待輸入 a。
  3. 顯示第二科提示，等待輸入 b。
  4. 計算 sum 和 ave。
  5. 顯示總分與平均。

總分為170

05｜範例 3-2｜使用暫存變數交換兩個數值

若 x = 1、y = 0，交換後應得到 x = 0、y = 1。為了避免第一個值被覆蓋，可以先用變數 t 暫時保存。

範例 3-2｜完整程式 · C++ 
#include <iostream>
using namespace std;

int main() {
    int x, y, t;
    cout << "請輸入兩個整數? ";
    cin >> x >> y;
    cout << "交換前 x=" << x << ", y=" << y << endl;
    t = x;
    x = y;
    y = t;
    cout << "交換後 x=" << x << ", y=" << y << endl;
    return 0;
}

互動｜觀察交換步驟

x1
y0
t尚未指定

步驟 0：尚未開始交換。

想一想：如果只寫 x = y; y = x; 會如何？

第一行 x = y; 已把原本的 x 覆蓋，第二行 y = x; 取到的是修改後的值。以 x=1、y=0 為例，最後兩者都會變成 0，並沒有真正交換。

習題 3-2｜圓的面積與周長

令 pi = 3.14，讓使用者輸入半徑 r，輸出圓的面積與周長。

r = 5 → 面積為 78.5，周長為 31.4

相關線上題目：a005

需要提示？

面積 = pi × r × r；周長 = 2 × pi × r。

習題 3-4｜華氏溫度換算

輸入華氏 95 度，計算攝氏溫度

習題 3-5｜英哩球速轉公里

輸入英哩球速 mile，將結果換算成公里 km。

1 英哩 = 1.6 公里

習題 3-6｜BMI 身高體重指數

輸入身高 height（公分）與體重 weight（公斤），計算 BMI。

BMI = 體重（kg）÷ 身高（m）的平方

相關線上題目：z019

需要提示？

先將公分除以 100 轉成公尺，再計算 weight / (h * h)。

習題 3-7｜整數相除的商與餘數

輸入兩個整數 m（被除數）與 n（除數），輸出整數商 q 與餘數 r。

例如 m=17、n=5 → 商 3，餘數 2
需要提示？

q = m / n; r = m % n;，除數 n 不得為 0。

習題 3-8｜秒數換算時分秒

輸入整數秒數 second，轉換成「時:分:秒」。

39016 秒相當於 10:50:16

相關線上題目：a007

需要提示？

1 小時為 3600 秒。先用 / 求時，用 % 求剩餘秒數，再算分與秒。

習題 3-9｜外匯換算

輸入新臺幣金額 money，按照指定匯率換算成美金與日幣。

匯率：1 美元 = 28.5 元新臺幣；1 日圓 = 0.26 元新臺幣。輸入 10000 元，約可換 350.877 美元、38461.538 日圓。
需要提示？

美金 = money / 28.5；日幣 = money / 0.26。匯率為本題指定數值。

習題 3-10｜西元年換算民國年

輸入西元年 AD，顯示民國年。

輸入 2022 → 西元2022年是民國111年

民國年 = 西元年 - 1911。

09｜延伸｜scanf、printf 與常用數學函式

C 與 C++ 標準輸入輸出比較

功能C 語言C++
輸入一個整數scanf("%d", &n);cin >> n;
輸入兩個變數scanf("%d %f", &n, &x);cin >> n >> x;
輸出整數printf("%d", n);cout << n;
輸出多個變數printf("%d %f", n, x);cout << n << " " << x;

常見格式符號：%c 對應字元 char，%d 對應整數 int，%f 對應 float（在 printf 傳入時會提升為 double）。

scanf / printf 完整範例 · C++ 
#include <cstdio>
using namespace std;

int main() {
    int n;
    float x;
    scanf("%d %f", &n, &x);
    printf("整數=%d, 實數=%f\n", n, x);
    return 0;
}

延伸運算工具

函式 / 工具作用與範例標頭檔
pow(2, 3)2 的 3 次方，得到 8<cmath>
sqrt(9)9 的平方根，得到 3<cmath>
log10(100)以 10 為底的對數，得到 2<cmath>
fixed << setprecision(2)固定顯示小數點後兩位<iomanip>
延伸｜小數位數與數學函式 · C++ 
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    cout << pow(2, 3) << endl;
    cout << sqrt(9) << endl;
    cout << log10(100) << endl;
    cout << fixed << setprecision(2) << 3.14159 << endl;
    return 0;
}
