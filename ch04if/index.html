01｜建立概念

原講義第 1 頁 · 程式流程控制

① 循序式程式一行接著一行，按照順序執行。

③ 迴路式重複執行流程，例如 while、for。

本章專注於「條件式」；迴路式將在後續章節介紹。

05｜範例 4-2
原講義第 2–3 頁 · 比較兩種寫法
輸入一個數字，判斷為正數、負數或零。先操作測試，再比較下方兩種 C++ 寫法。
 
方法 1｜if－else if－else（建議）
查看範例 4-2 方法 1 C++ 程式碼
#include <iostream>
using namespace std;

int main() {
    float num;
    cout << "請輸入一個數字?";
    cin >> num;

    if (num > 0) {
        cout << num << "是正數" << endl;
    } else if (num < 0) {
        cout << num << "是負數" << endl;
    } else {
        cout << num << "是零" << endl;
    }
    return 0;
}
方法 2｜三個獨立 if
查看範例 4-2 方法 2 C++ 程式碼
#include <iostream>
using namespace std;

int main() {
    float num;
    cout << "請輸入一個數字?";
    cin >> num;

    if (num > 0) {
        cout << num << "是正數" << endl;
    }
    if (num < 0) {
        cout << num << "是負數" << endl;
    }
    if (num == 0) {
        cout << num << "是零" << endl;
    }
    return 0;
}
兩種寫法都能判斷正數、負數與零；因為三種結果互斥，建議使用方法 1，結構較清楚。
06｜範例 4-3
原講義第 3–4 頁 · 使用 && 組合條件
輸入國文、英文、數學三科分數，假如三科都大於等於 80，顯示「很優秀」，否則顯示「再加油!」。
試試複合條件
  
查看範例 4-3 C++ 程式碼
#include <iostream>
using namespace std;
int main() {
    float chi, eng, math;
    cin >> chi >> eng >> math;
    if (chi >= 80 && eng >= 80 && math >= 80) {
        cout << "很優秀" << endl;
    } else {
        cout << "再加油!" << endl;
    }
    return 0;
}
範例 4-3｜程式講解與巢狀 if 比較
「三科都大於等於 80」表示國文、英文、數學三個條件必須同時成立，因此使用 &&。
延伸：巢狀 if 是什麼？（含完整 C++ 程式）
if 裡面再包含 if 稱為「巢狀 if」。原講義第 4 頁示範以巢狀判斷完成三科成績檢查，但也提醒這樣的結構較複雜，不建議在此題使用。
#include <iostream>
using namespace std;

int main() {
    float chi, eng, math;
    cout << "請輸入國文、英文、數學分數?";
    cin >> chi >> eng >> math;

    if (chi >= 80) {
        if (eng >= 80) {
            if (math >= 80) {
                cout << "很優秀" << endl;
            } else {
                cout << "再加油!" << endl;
            }
        } else {
            cout << "再加油!" << endl;
        }
    } else {
        cout << "再加油!" << endl;
    }
    return 0;
}
