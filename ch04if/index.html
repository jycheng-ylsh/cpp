01｜建立概念：程式如何決定方向？

原講義第 1 頁 · 程式流程控制

① 循序式程式一行接著一行，按照順序執行。
② 條件式條件符合才執行，例如 if。
③ 迴路式重複執行流程，例如 while、for。

本章專注於「條件式」；迴路式將在後續章節介紹。

範例 4-2｜正數或負數
原講義比較「if...else」與「兩個獨立 if」的寫法，並請學生進一步修改，讓 0 顯示為零。
 
查看三種結果的建議寫法
if (num > 0) {
    cout << "正數";
} else if (num < 0) {
    cout << "負數";
} else {
    cout << "零";
}
範例 4-3｜三科都達 80 分
三科分數必須全部達到 80 分，使用 && 連接三個條件。可到上方「運算子」區操作。
if (chi >= 80 && eng >= 80 && math >= 80) {
    cout << "很優秀" << endl;
} else {
    cout << "再加油!" << endl;
}
05｜例題講解：為什麼這樣寫？
先看條件num > 0 是判斷式，不是輸出指令。
比較寫法同一組互斥結果通常可用 if...else 表達。
組合條件「三科都」表示每科都要達標，因此使用 &&。
延伸：巢狀 if 是什麼？
if 裡面再包含 if 稱為「巢狀 if」。原講義第 4 頁示範以巢狀判斷完成三科成績檢查，但也提醒這樣的結構較複雜，不建議在此題使用。
